# График настроения

Бесплатная минимальная таблица для ежедневной записи сна, приёма лекарств и
изменений настроения. Работает в современном браузере на iPhone, Android,
Windows и macOS.

Автор: **KoreNat** · версия **v.1.1**

## Как пользоваться

1. Откройте файл `mood_diary.html` в браузере.
2. Выберите язык, укажите месяц и год.
   Кнопка **Info** справа вверху открывает эту инструкцию внутри приложения.
3. В строке «Часы сна» нажмите на клетку нужного дня и введите число или текст.
4. В остальных строках одно нажатие ставит крестик. Повторное одиночное
   нажатие убирает его.
5. Двойное нажатие на клетку открывает окно записи. Там можно указать несколько
   времён, каждое с новой строки или через запятую, и при необходимости добавить
   пояснение. Нажмите «Сохранить», чтобы закрыть окно.
6. Таблицу можно двигать пальцем или горизонтальной полосой прокрутки, чтобы
   перейти к следующим дням месяца.

Основная кнопка «Сохранить» записывает текущее состояние в браузере. Под
кнопками показываются дата и время последнего сохранения.

«Скачать заполненную копию» создаёт новый HTML-файл со всеми внесёнными
записями. Его можно сохранить как резервную копию, перенести на другое
устройство или переслать по электронной почте. «Печать / PDF» открывает
системное окно печати. «Очистить таблицу» удаляет записи после подтверждения.

Шкала настроения использует уровни от +3 до −3. Интерфейс доступен на русском,
английском, украинском, нидерландском и корейском языках.

## Конфиденциальность и безопасность

Приложение состоит из одного небольшого HTML-файла. Ему не нужны регистрация,
учётная запись, подписка или оплата. В нём нет рекламы, аналитики и внешних
библиотек.

Все записи хранятся только у пользователя: в локальном хранилище выбранного
браузера и, если пользователь нажал «Скачать заполненную копию», внутри этой
копии. Приложение не отправляет записи на сервер и не выполняет сетевых
запросов. Доступ к микрофону, камере, геолокации и контактам не используется.

Заполненный файл может содержать личную медицинскую информацию, поэтому его
следует хранить и пересылать как конфиденциальный документ. Очистка данных
браузера или удаление файла может уничтожить единственную копию записей; для
резервного хранения периодически скачивайте заполненную копию.

Использование приложения бесплатно. Платных функций и встроенных покупок нет.

